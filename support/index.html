계정·데이터 삭제 요청

Coldcase Lab 계정에는 로그인 정보(이메일 주소 또는 카카오 회원번호·닉네임)와 에피소드별 진행도(점수·완료 시각·시도 횟수)만 저장됩니다.

가장 빠른 방법: 앱이나 웹의 계정 페이지에서 로그인한 뒤 “계정 삭제” → “정말 삭제”를 누르면 계정과 진행도가 즉시 지워집니다.

로그인할 수 없다면 이메일로 요청할 수 있습니다:

  1. 로그인에 쓴 이메일 주소로 gptalt1729@gmail.com에 제목 “[Coldcase Lab] 계정 삭제 요청”으로 메일을 보냅니다. (본인 확인을 위해 로그인 주소에서 보내 주세요.)
  2. 요청 접수 후 7일 안에 계정과 계정에 연결된 진행도를 모두 삭제하고, 완료 메일을 보냅니다.

삭제되는 데이터: 이메일 주소, 계정에 연결된 진행도 전부. 남는 데이터: 개인과 연결되지 않은 익명 집계 통계(열쇠별 정답률)는 계정 정보를 포함하지 않으므로 그대로 남습니다. 추가 보관 기간은 없습니다. 이 기기(브라우저 저장소)의 진행도는 앱 데이터 삭제 또는 브라우저 데이터 삭제로 지울 수 있습니다.

계정을 유지한 채 진행도만 지우고 싶다면 같은 방법으로 “진행도 삭제 요청”이라고 보내 주세요.
